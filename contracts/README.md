# Ausführbare Verträge

Dieses Verzeichnis enthält sprachübergreifende Verträge zwischen
Datenproduzenten und -konsumenten. Änderungen sind wie öffentliche
Schnittstellen zu behandeln und benötigen eine neue Version, wenn bestehende
App-Versionen den Datensatz nicht mehr lesen können.

Der aktuelle Ladebestand ist unter `charging_dataset/v1/` definiert.
