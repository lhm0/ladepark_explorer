# Archiv

Dieses Verzeichnis enthält historische Übergaben und Arbeitsvorschläge. Die
Dokumente erklären frühere Überlegungen, sind aber keine verbindliche Quelle
für den aktuellen Produkt- oder Implementierungsstand.

Maßgeblich sind in dieser Reihenfolge:

1. `PROJECT_STATUS.md` für den verifizierten Ist-Zustand,
2. `docs/specification/` für Produkt- und Systemspezifikation,
3. angenommene Entscheidungen unter `docs/adr/`,
4. der tatsächliche Repository-Zustand und erfolgreiche Prüfungen.

  Spezifikationskerns,
