# Coding Guidelines

Status: Gerüst – mit der Implementierung zu konkretisieren

- SOLID
- Clean Architecture
- kleine Klassen
- hohe Testabdeckung

Projektspezifische, automatisiert überprüfbare Regeln werden erst mit der
jeweiligen Codebasis festgelegt. Allgemeine Stilregeln sollen möglichst durch
Formatter und Linter statt durch umfangreiche Prosa erzwungen werden.
